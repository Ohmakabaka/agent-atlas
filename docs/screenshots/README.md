# 界面与截图

截图取自实际运行的生产构建，不是设计稿。数据库会随收录和审核变化，画面中的数量不应当成固定产品限制。

| 截图                     | 内容                                             |
| ------------------------ | ------------------------------------------------ |
| [home.png](home.png)     | 桌面技术地图、主题方向、阅读专题、资料与工程实践 |
| [mobile.png](mobile.png) | 手机端导航、技术地图与内容布局                   |
| [topic.png](topic.png)   | 主题概述、阅读路径、分层资料与关联线索           |
| [graph.png](graph.png)   | 关系图、聚焦节点、证据列表与筛选入口             |

主要页面可以从导航与后台复现：

| 页面                   | 查看重点                                  |
| ---------------------- | ----------------------------------------- |
| `/`                    | 问题导向的技术地图和内容发现              |
| `/topics/architecture` | 主题概述、分层资料和跨主题阅读路径        |
| `/articles/react`      | 原始出处、中文导读、证据关系、收藏与已读  |
| `/explore`             | 中文/英文相关度搜索、组合条件、排序和分页 |
| `/graph`               | 有向关系、节点聚焦和等价证据列表          |
| `/timeline`            | 原文发布时间、主题与内容类型筛选          |
| `/sources`             | 来源目录与已收录资料                      |
| `/library`             | 本机阅读记录、状态筛选与导入导出          |
| `/about`               | 编辑准则、内容分层、版权与贡献方式        |
| `/admin`               | 登录后收录、修订、审核、发布及版本历史    |
| `/admin/topics`        | 主题层级、排序与跨主题阅读路径维护        |
| `/admin/jobs`          | 来源健康、调度状态与人工重试              |
| `/admin/audit`         | 编辑与认证审计                            |

后台截图不得包含口令、会话、模型凭证或个人信息。阅读库截图若含私人阅读记录，应先征得持有者同意或使用明确的测试记录。重新生成截图应使用同一目标构建并检查浏览器运行时错误。
