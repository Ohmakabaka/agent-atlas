# 界面与截图

`home.png` 展示桌面端技术地图首页：问题导向的搜索入口、七个主题方向、阅读专题、最新资料、工程实践和来源导航。截图取自真实运行页面，不是设计稿。

主要页面可以从导航复现：

| 页面                   | 查看重点                       |
| ---------------------- | ------------------------------ |
| `/`                    | 技术地图和内容发现             |
| `/topics/architecture` | 主题概述、分层资料与阅读路径   |
| `/explore`             | 中文搜索、组合条件与分页       |
| `/timeline`            | 按原文发布日期浏览并按主题筛选 |
| `/sources`             | 来源与已收录资料               |
| `/admin`               | 登录后收录、修订、审核和发布   |

截图随数据增长可能与当前页面计数不同。提交后台截图前，移除输入的密码、模型配置和其他私人内容。
